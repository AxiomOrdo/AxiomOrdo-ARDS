ARDS Certification Programme

Independent, market-trusted certification for compliance software. The ARDS Certification Mark signals to regulators, enterprise buyers, and system integrators that your product speaks the standard.

Six Certification Levels

Each level builds on the last. L1–L2 are self-declared. L3–L6 require AxiomOrdo assessment.

L1
Schema-Valid
ARDS-SV
Self-declare · Free
Your artefacts validate without errors against the JSON Schema identified in ards:meta.schemaId.
✓ Pass JSON Schema validation for all produced artefacts
✓ Declare schema URI correctly in ards:meta.schemaId
✓ Run ards-validate --level schema-valid with zero errors
L2
ARDS Core Conformant
ARDS-CC
Self-declare · Free
Your artefacts implement the full ards:meta envelope with all required fields meeting normative format requirements.

✓ Pass ards-validate --level core-conformant with zero errors

How to Apply

Eight stages from application to issued token. L1–L2 are self-declared. L3–L6 go through formal assessment.

1

Pre-Application

Complete the product readiness checklist and run ards-validate against your outputs. Download the assessment guide from the registry.

2

Application Form

Submit via standards@axiomordo.com. Include product description, claimed conformance level, target domain packs, and a sample artefact set.

3

Scoping Call

30-minute call with the AxiomOrdo Certification Committee to confirm scope, agree the test plan, and schedule the assessment window.

4

Technical Assessment

AxiomOrdo runs your product against the conformance test suite. You receive a detailed test report with pass/fail status for every test case.

5

Remediation (if needed)

One remediation cycle is included. Fix any failures and re-submit the affected test cases within 60 days at no additional cost.

6

Decision

The Certification Committee issues a formal decision. Successful applicants receive a Certification Report and a draft token for review.

7

Token Issuance

On fee confirmation, AxiomOrdo signs and publishes your Certification Token to the registry. You receive the signed JSON file for embedding.

8

Directory Listing

Your product appears in the ARDS Certified Directory at registry.axiomordo.com/certified, searchable by level, domain pack, and jurisdiction.

Trust Mark Usage Policy

The ARDS certification marks are licensed exclusively to holders of valid Certification Tokens. Use is governed by the following rules.

✓ Permitted

  • Use on product pages, data sheets, and sales materials
  • Embed the Certification Token in your ARDS artefacts
  • Reference certification level in RFP responses
  • Display on integration partner listings

✗ Not Permitted

  • Use after token expiry without renewal
  • Claim a higher level than certified
  • Apply marks to uncertified products or services
  • Modify or reproduce the mark artwork

Verification

Anyone can verify a certification token in real time at:

registry.axiomordo.com/verify/{certificateId}

The endpoint returns the full token JSON and current validity status.
