ARDS Schema Registry

The authoritative registry of all canonical ARDS schemas, domain packs, and registered extension namespaces. All URIs are permanently resolvable and versioned.

Schema URI Pattern

Every ARDS schema has a canonical, permanently resolvable URI. Resolving the URI returns the JSON Schema document.

https://schema.axiomordo.com/ards/{ardsVersion}/{family}/{schema-name}.schema.json

# Examples:
https://schema.axiomordo.com/ards/1.0/meta/ards-meta.schema.json
https://schema.axiomordo.com/ards/1.0/obligation-record/obligation-record.schema.json
https://schema.axiomordo.com/ards/1.0/fueleu/obligation-record.schema.json
https://schema.axiomordo.com/ards/1.0/cbam/embedded-carbon-declaration.schema.json

Registered Extension Namespaces

Third-party extensions must register their namespace prefix in the ARDS Extension Registry. Registered namespaces are reserved globally.

PrefixOrganisationDomainStatusContact
fueleu: AxiomOrdo Group FuelEU Maritime Reserved standards@axiomordo.com
cbam: AxiomOrdo Group EU CBAM Reserved standards@axiomordo.com
pfas: AxiomOrdo Group PFAS Restriction Preview standards@axiomordo.com
ets: AxiomOrdo Group EU ETS Preview standards@axiomordo.com
x-* Any implementor Vendor-specific Open No registration required
To register a new namespace prefix, submit an RFC via the RFC process. Registrations are first-come, first-reserved.
